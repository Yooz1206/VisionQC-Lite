# VisionQC-Lite

**面向小样本工业场景的金属垫片表面缺陷视觉检测系统**

> 无深度学习、无训练样本、纯前端推理。用极坐标环形展开 + 自适应背景抑制 + 角度一致性滤波，在可控合成数据集上达到 Precision 98.07% / Recall 98.89% / F1 98.48%，误检从传统方案的数千框降至 7 框。

---

## 1. 这是什么

产线上金属垫片的划痕、缺口、污渍通常靠人工目检。人眼在长时间重复作业后漏检率上升，而深度学习方案又依赖大量标注样本，小批量多品种场景难以落地。

VisionQC-Lite 是一个**规则驱动、可解释、零训练成本**的视觉检测原型：

- 输入：128×128 灰度垫片图像
- 输出：缺陷位置框 + 类型 + 置信度（残差峰值）
- 部署：浏览器直接打开 `demo/index.html` 即可现场演示，**单文件自包含、无需服务器、无需安装依赖**

## 2. 核心方法

传统方案直接在笛卡尔坐标上设阈值，光照渐变和金属拉丝纹理会被误判为缺陷。本文方法分四步：

1. **环形 ROI 极坐标展开**：将半径 [22, 52] 的环形区域展开为 360×30 的矩形条带（角度 × 半径）。垫片的旋转不变性在此表示下自然成立，缺陷变成局部亮斑。
2. **环向循环平滑**：在角度方向使用循环卷积（`boxBlurCircular`），消除极坐标接缝处的伪边缘。
3. **自适应背景抑制**：大窗口（61×15）估计缓变背景，残差 = 平滑图 − 背景，抵消单侧暗 / 局部反光等光照工况。
4. **角度一致性滤波**：候选连通域必须满足角度跨度 ≥ 4 列、面积 ≥ 5 px、残差峰值 ≥ 20，排除孤立纹理噪点。

### 消融实验（480 张可控合成图）

| 方案 | Precision | Recall | F1 | 误检框数 |
|---|---|---|---|---|
| A 全局 Otsu 阈值 | 0.0292 | 0.5111 | 0.0553 | 6113 |
| B 笛卡尔局部背景抑制 | 0.0577 | 0.9694 | 0.1090 | 5695 |
| C 极坐标展开（无一致性滤波） | 0.0819 | 1.0000 | 0.1513 | 4038 |
| **D 本文完整方法** | **0.9807** | **0.9889** | **0.9848** | **7** |

关键结论：极坐标展开把召回率拉到 100%，角度一致性滤波把误检从 4038 降到 7 —— 两个模块各自解决不同问题，缺一不可。

### 分缺陷类型

| 类型 | 检出 / 总数 | Recall | Precision |
|---|---|---|---|
| 划痕 scratch | 120 / 120 | 1.0000 | 0.9677 |
| 缺口 notch | 120 / 120 | 1.0000 | 1.0000 |
| 污渍 stain | 116 / 120 | 0.9667 | 0.9748 |

### 速度

单张 128×128 图像推理 **0.874 ms**（≈1144 FPS，Node 单线程 CPU，纯 JS）。

## 4. 快速开始

```bash
# 1) 现场演示：直接用浏览器打开
start demo/index.html        # Windows
# open demo/index.html       # macOS

# 2) 复现评测（需要 Node.js 18+）
node src/evaluate.js 480
cat reports/evaluation.json

# 3) 重新生成答辩用图
node src/make_figures.js

# 4) 修改演示页 UI 或核心算法后，重建自包含演示页
node src/build_demo.js
```

评测使用固定种子 `SEED=2026`，任何人运行都得到相同数字。

## 5. 适用范围与边界（诚实声明）

- **适用**：圆环状金属零件、纹理规律性强的表面、光照缓变或单侧渐变工况。
- **不适用 / 已知边界**：
  - 数据集为**程序化合成图像**，并非真实工厂采集；真实产线的油污、氧化皮、镜头畸变尚未验证。
  - 极坐标展开依赖已知的圆心与内外半径；圆心偏移 > 3 px 时需先加定位步骤。
  - 污渍类低对比缺陷仍有 3.3% 漏检，需人工复核。
  - 图像固定为 128×128 灰度；彩色 / 高分辨率输入需先做缩放与灰度化。

这些边界在答辩中主动出示，而不是隐藏 —— 它们定义了方法的真实适用范围。
