# VisionQC-Lite / VisionQC-Studio

**面向小样本工业场景的金属垫片表面缺陷视觉检测系统（YOLO 主线 · 双引擎可解释工作台）**

> YOLO 是检测骨干，不是创新点。本项目的贡献是：**可控数据集构造**（缺陷类型 × 光照 × 旋转）、**极坐标先验流程**、以及**同一工作台内 YOLO 与规则引擎的逐张可解释对照**。

---

## 1. 这是什么

产线上金属垫片的划痕、缺口、污渍靠人工目检，长时间重复作业后漏检率上升。深度学习检测器精度高，但小批量多品种场景缺标注数据、部署门槛高。

本项目给出一个完整工作台，把两条路线放在同一界面：

- **YOLO 主检测器**：上传照片 → ONNX 推理 → 缺陷框与类别置信度；支持批量、导出。
- **规则引擎基线**：零训练样本、纯前端推理，极坐标展开 + 自适应背景抑制 + 角度一致性滤波，F1 = 98.48%（可控合成数据），用于可解释对照与消融。

二者不是二选一：工作台把规则结果画成绿色虚线，把 YOLO 结果画成橙色实线，便于逐张分析各自边界。

## 2. 创新点表述（答辩用）

1. **可控数据构造**：程序化生成 3 类缺陷 × 3 种光照 × 随机角度，像素级真值、固定种子可复现，解决小样本场景“数据从哪来”。
2. **极坐标先验**：把环形 ROI 展开为 360×30 条带，旋转不变性显式编码进表示；既可作为规则检测核心，也可作为 YOLO 输入增强通道。
3. **双引擎可解释对照**：同一张图上同时给出 YOLO 与规则结果，用消融量化每个模块的作用，避免“用了 YOLO 就是创新”的伪创新。

## 3. 数据集（YOLO 格式）

```bash
node src/make_yolo_dataset.js 800
```

生成 `dataset/yolo/`：

- `images/{train,val}`：800 张 128×128 灰度图（RGB 编码），640 训练 / 160 验证
- `labels/{train,val}`：YOLO 归一化标签 `class cx cy w h`
- `data.yaml` / `classes.txt` / `manifest.csv`（种子、缺陷类型、光照、真值框）

三类缺陷各 200 个标注对象，另有 200 张正常样本（空标签）。

## 4. YOLO 训练与网页推理

```bash
pip install -r requirements-yolo.txt
python train_yolo.py --epochs 80 --imgsz 640 --batch 16
python export_onnx.py --weights runs/visionqc/washer_yolo11n/weights/best.pt
```

打开 `studio/index.html` → “载入 YOLO 模型”选择 `.onnx` → 上传/拖入图片 → 运行。页面通过 onnxruntime-web 完成 letterbox、推理、解码、NMS 和坐标还原，首次加载需要联网获取运行时。

> 诚实说明：本机没有深度学习训练环境，训练脚本已交付但未在此环境实际训练；演示页在未载入模型时明确提示并回退到规则引擎，不会伪造 YOLO 结果。

详细步骤见 `docs/YOLO_TRAINING.md`。

## 5. 规则引擎方法与结果（可复现基线）

1. **环形 ROI 极坐标展开**：半径 [22, 52] → 360×30 条带（角度 × 半径），旋转不变性自然成立。
2. **环向循环平滑**：角度方向循环卷积，消除极坐标接缝伪边缘。
3. **自适应背景抑制**：大窗口（61×15）估计缓变背景，残差 = 平滑图 − 背景，抵消渐变/反光。
4. **角度一致性滤波**：候选连通域需满足角度跨度 ≥ 4 列、面积 ≥ 5 px、残差峰值 ≥ 20。

消融实验（480 张可控合成图，固定种子 2026）：

| 方案 | Precision | Recall | F1 | 误检框数 |
|---|---|---|---|---|
| A 全局 Otsu 阈值 | 0.0292 | 0.5111 | 0.0553 | 6113 |
| B 笛卡尔局部背景抑制 | 0.0577 | 0.9694 | 0.1090 | 5695 |
| C 极坐标展开（无一致性滤波） | 0.0819 | 1.0000 | 0.1513 | 4038 |
| **D 完整规则方法** | **0.9807** | **0.9889** | **0.9848** | **7** |

单张推理 **0.874 ms**（≈1144 FPS，Node 单线程 CPU，纯 JS）。

## 6. 工作台功能

- 单张 / 批量上传，拖拽导入，自动缩放到最长边 512px
- 环形 / 矩形 ROI，自动定位 + 手动圆心与半径调整（点击原图设圆心）
- 10 个可启停、可排序、可调参的流程模块：灰度、去噪、对比度、ROI、极坐标展开、平滑、背景抑制、分割、一致性滤波、输出
- 四种预设：标准 / 高灵敏 / 严格 / 笛卡尔
- 四路实时视图：原图+ROI、极坐标展开、残差/分割掩膜、检测结果
- 模块执行日志、批量结果表、CSV / JSON / PNG 导出、流程配置保存与加载
- YOLO ONNX 主检测器接入，与规则基线同屏叠加对照
- **实拍图一键缺口检测**：自动定位银色圆标记（十字+C 坐标）、自动框出工件与缺口、OK/NG 判定；内置 3 张实拍样例
- 内置「使用指南」弹窗，完整步骤见 `docs/USER_GUIDE.md`

## 9. 适用范围与边界（诚实声明）

- **适用**：圆环状金属零件、纹理规律性强的表面、光照缓变或单侧渐变工况。
- **边界**：
  - 数据为程序化合成图像，真实产线的油污、氧化皮、镜头畸变尚未验证。
  - 极坐标展开依赖已知圆心与内外半径；偏移 > 3 px 需先定位。
  - 污渍类低对比缺陷有 3.3% 漏检，需人工复核。
  - 规则引擎固定 128×128 灰度；YOLO 通道支持任意尺寸上传图。
  - YOLO 权重未在本机训练，需用户按脚本训练后导入 ONNX。
