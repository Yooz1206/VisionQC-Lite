使用指南 · 实拍缺口检测

本工作台针对托盘中的方形工件：自动定位银色圆标记作为基准，再用凸包空缺检测缺口。整个过程只需 2 步。

① 最快上手（推荐）

  1. 左侧第 5 区点击 样例 1 / 2 / 3，或把你的照片拖到上方“载入样本”区域。
  2. 点击 ◎ 一键定位圆 + 检测缺口。结果立即显示：OK 合格 / NG 有缺口。

画面中：青色十字 + C 标记 = 自动定位的圆心；黄色虚线框 = 自动识别的工件范围；红色粗框 = 检测到的缺口。右下“判定”栏同时给出圆心像素坐标、缺口框与面积。

② 用自己的照片

  • 点击左侧“载入样本”虚线框选择 JPG/PNG，可一次多选做批量；也可直接拖拽。
  • 建议拍摄：工件位于画面中央、背景较暗、圆标记完整可见；分辨率不限，页面自动缩放。
  • 若工件不在画面中央导致分割失败，先在“检测区域 ROI”选矩形并框住工件，再点一键检测。
  • 误报偏多时把“灵敏度”调到 0.7；漏报时调到 1.5。

③ 流程编排与导出（可选）

  • 右侧可勾选 / 排序 / 调参各模块，关闭“极坐标展开”即切换笛卡尔模式，关闭“一致性滤波”可看误检变化。
  • 第 4 区载入训练导出的 ONNX 后，YOLO 成为主检测器（橙色框），规则引擎以绿色虚线作对照。
  • 底部可 批量检测全部，并导出 CSV / JSON 报告 / 当前结果 PNG。

④ 结果怎么看

缺口面积占工件面积约 4.6%（样例 1）判为 NG；设计性小圆角约 0.7% ~ 1.1%（样例 2、3）判为 OK。默认阈值 1.4%，可在灵敏度里微调。

边界说明：本方法是无训练的无监督几何检测，适合背景简洁、轮廓清晰的场景；强反光、工件严重遮挡或圆标记缺失时需人工复核。它不替代 YOLO 分类模型。
