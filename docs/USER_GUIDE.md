# VisionQC-Studio 使用指南（实拍缺口检测）

适用版本：v1.3.0 · 文件：`studio/index.html`（单文件，双击即可打开，无需服务器）

## 1. 三步完成一次检测

| 步骤 | 操作 | 结果 |
|---|---|---|
| ① 打开 | 双击 `studio/index.html` | 工作台启动，默认带一张合成示例 |
| ② 载入 | 左侧第 5 区点「样例 1 / 2 / 3」，或把照片拖进「载入样本」 | 图片出现在缩略图并自动显示 |
| ③ 检测 | 点「◎ 一键定位圆 + 检测缺口」 | 自动圈出圆标记、框出缺口、给出 OK/NG |

不需要先设置 ROI、不需要训练模型、不需要调阈值。

## 2. 界面标记含义

- **青色十字 + 圆圈 + `C (x,y)`**：自动定位的银色圆标记中心（像素坐标）。
- **黄色虚线框**：算法自动识别的工件本体范围（已同步写入 ROI 输入框）。
- **红色粗框 + `缺口 Npx`**：检出的缺口区域及其像素面积，仅 NG 时出现。
- **绿色虚线框**：规则引擎基线框（与 YOLO 同屏时作为对照）。
- **橙色实线框**：载入 ONNX 后的 YOLO 主检测结果。
- **右下「判定」区**：OK / NG、圆心坐标、缺口框、缺口面积、判定依据。

## 3. 三张实拍样例的实际结果

| 样例 | 圆心 (px) | 最大空缺面积 | 占比 | 判定 |
|---|---|---|---|---|
| 样例 1 | (277, 136) | 3209 px | 4.55% | **NG — 左下角缺口** |
| 样例 2 | (376, 319) | 842 px | 1.11% | OK — 设计性圆角 |
| 样例 3 | (273, 144) | 568 px | 0.75% | OK — 设计性圆角 |

判定阈值：最大空缺面积 > `max(700, 工件面积 × 1.4%)` 即判 NG。可在「灵敏度」里调整（数值越大越灵敏）。

## 4. 上传自己的照片

1. 点击左侧「点击选择或拖拽图片到此处」，选择 JPG / PNG / BMP；可一次多选。
2. 批量模式：先点上方「批量」标签再选图，之后点「批量检测全部」。
3. 拍摄建议：工件尽量居中、背景较暗、银色圆标记完整可见、避免强反光遮挡轮廓。
4. 若工件偏离画面中央导致分割失败：
   - ROI 类型改为「矩形」，手动框住工件，再点一键检测；
   - 或修改 `src/chip-inspect.js` 里 `region` 的默认比例。
5. 误报偏多 → 灵敏度调到 `0.7`；漏报 → 调到 `1.5`。

## 5. 进阶：流程编排与 YOLO

- 右侧面板可勾选 / 上下排序 / 调参 10 个模块。关闭「极坐标展开」切换为笛卡尔背景抑制；关闭「一致性滤波」可观察误检数量变化。
- 第 4 区点「载入 YOLO 模型 (.onnx)」，导入 `export_onnx.py` 导出的模型后，YOLO 成为主检测器；未载入时明确提示并回退规则引擎，不会伪造结果。
- 修改 `demo/studio.template.html` 或 `src/chip-inspect.js` 后，必须运行：

```bash
node src/build_studio.js
```

重新生成自包含的 `studio/index.html`。

## 6. 导出

- **CSV**：含规则框、YOLO 框、圆心坐标、缺口判定字段。
- **JSON**：完整配置 + 每张图结果 + 圆/缺口检测结果。
- **PNG**：当前结果图（含圆十字与缺口框）。
- **保存流程 / 打开流程**：流程参数 JSON，便于复现实验。

## 7. 算法边界（请如实说明）

- 无训练、无监督的几何方法，依赖「工件与背景有灰度差 + 圆标记可辨」。
- 圆心偏移过大、工件严重遮挡、强反光或圆标记缺失时可能失效，需要人工复核。
- 本方法不是 YOLO 分类模型的替代；YOLO 用于缺陷类别识别，本方法用于零样本几何缺口筛查与可解释对照。

## 8. 常见问题

**Q：点一键检测提示「未分割出工件」？**
A：图像整体过曝/欠曝，或工件超出中心区域。改用矩形 ROI 框住工件后重试。

**Q：OK 的图也显示了一个候选空缺面积？**
A：那是工件设计性小圆角，处于阈值以下，不算缺口；页面已把 OK 的缺口框显示为「—」。

**Q：预览面板里图片没出来？**
A：确认使用 `studio/index.html`（自包含版），不要用 `demo/studio.template.html`；后者是模板，需重建。
